## Arquitectura definida

La idea es NO meter todos los servicios en un solo contenedor.

Cada aplicación tendrá:

* su propio contenedor
* sus propios datos persistentes
* su propia configuración
* su propia base de datos cuando corresponda

Ejemplo futuro:

```
Docker

├── Odoo
│    ├── container
│    ├── PostgreSQL database
│    └── storage
│
├── Nextcloud
│    ├── container
│    ├── database propia
│    └── storage propio
│
├── Grafana
│
├── Prometheus
│
├── Redis
│
└── otros servicios
```

No compartir bases entre aplicaciones salvo que exista una razón concreta.
