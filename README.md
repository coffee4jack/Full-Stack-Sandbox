# Full-Stack-Sandbox
This is a full stack project for learning.

Backend: Django
Frontend: React

## Getting Started

```bash
# Backend
cd Backend\djbackend\testapi
python manage.py runserver

# Frontend
cd Frontend\djfrontend\testapi
npm run dev
```
